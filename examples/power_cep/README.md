# Power capacity expansion planning example

This example demonstrates a small two-stage stochastic capacity expansion
planning model for power systems using `mpi-sppy`.

## Model overview

- **First stage**: build new generation capacity
  - integer gas build blocks of 50 MW
  - continuous wind MW
  - continuous solar MW
- **Second stage**: dispatch generation and allow load shedding
- **Uncertainty**: demand and generator availability across representative hours

The example uses a simple copper-plate formulation with no network, no unit
commitment, and no ramping.

## Representative hours

The model uses 6 seasonal/condition labels:

- `winter_night`
- `winter_day`
- `spring_day`
- `summer_afternoon_peak`
- `summer_evening_peak`
- `fall_shoulder_day`

Each hour has an annual weight so operational costs are on the same basis as
annualized investment costs.

## Running the example

From `examples/power_cep/`:

```bash
python -m mpisppy.generic_cylinders --module-name power_cep --num-scens 3 --EF --EF-solver-name highs
```

For a parallel PH run with bound-producing spokes:

```bash
mpiexec -n 6 python -m mpi4py -m mpisppy.generic_cylinders \
    --module-name power_cep --num-scens 3 --solver-name highs \
    --default-rho 2.0 --lagrangian --xhatshuffle \
    --linearize-proximal-terms --max-iterations 50
```

## Tuning and pedagogy

Use `tune_power_cep.py` to compute the same comparison metrics used in the
battery sizing teaching example:

- EV
- RP
- WS
- EEV
- VSS
- EVPI

Example:

```bash
python tune_power_cep.py --num-scens 3 --solver-name highs
```

## Files

- `power_cep.py`: model and mpi-sppy callbacks
- `scenario_generator.py`: stochastic data generation
- `system_data.json`: deterministic system data
- `tune_power_cep.py`: EV/RP/WS/VSS/EVPI tuning report
